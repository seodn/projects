# SEO Plan PDF Workflow

Use this workflow when creating a client-friendly SEO plan PDF for any website.

## Required Inputs

Ask the user for these inputs before making the plan:

- Website URL that needs the SEO plan.
- Our website Ahrefs/SEO metrics screenshot.
- Competitor Ahrefs/SEO metrics screenshot.
- Initial ranking screenshot or keyword list.
- Any special location focus, for example Auckland, New Zealand, Sydney, or nationwide.
- Any special service/product focus, for example beds, packaging, used hybrid cars, finance, local store, ecommerce products.

## Tone And Style

The plan must be easy for a client to understand.

- Use simple language.
- Avoid heavy technical words.
- Explain what we will do and why it matters.
- Highlight important points using callout boxes or bold text.
- Keep paragraphs short.
- Use tables for comparison, timelines, and action plans.
- Do not make it sound negative. Frame gaps as opportunities.
- Do not promise guaranteed rankings.

Good wording:

> The website has a base to improve from. The next step is to build stronger local trust, improve important pages, and make the site easier for Google and AI search tools to understand.

Avoid wording like:

> The website is bad and has poor technical SEO.

## Website Review Step

Open and review the live website before writing the plan.

Check:

- Homepage message.
- Main products/services.
- Location details.
- Footer address, phone, and business details.
- Contact page.
- Main category/service pages.
- Trust signals such as reviews, certifications, guarantees, delivery, finance, case studies, or testimonials.
- Blog/help content.
- Local SEO signals.
- Whether the site has clear pages for the target locations.

## Screenshot Handling

Use the screenshots supplied by the user.

Add screenshots for:

- Our website metrics.
- Competitor website metrics.

Do not add the initial ranking screenshot unless the user asks for it.

For initial ranking, create a clean table with only:

| Keyword | Current Position |
|---|---|

Example:

| Keyword | Current Position |
|---|---|
| packaging solutions | 5 |
| custom pack | 4 |
| packaging products | 38 |

## Metrics Comparison Section

Create a simple comparison table.

Use available screenshot metrics such as:

- DR
- UR
- Backlinks
- Referring domains
- Organic keywords
- Organic traffic
- Top 3 keywords
- AI Overview / AI citations
- ChatGPT citations
- Paid keywords, if useful
- Google Business Profile reviews, if provided

Example table:

| Metric | Our Site | Competitor | Meaning |
|---|---:|---:|---|
| DR | 5 | 12 | Competitor has stronger domain authority. |
| Backlinks | 365 | 23.2K | We need more quality links and citations. |
| Organic keywords | 9 | 528 | We need more pages targeting buyer searches. |
| AI citations | 0 | 5 | We need AI-ready content structure. |

## Main Plan Structure

Use this structure for most SEO plan PDFs:

1. Cover page
2. Executive summary
3. Current situation
4. Metrics comparison
5. Metrics screenshots
6. Initial ranking baseline
7. SEO strategy
8. 30/60/90-day plan or 3/6/12-month plan
9. Page roadmap
10. Local SEO plan
11. AI SEO plan
12. Technical/on-page priorities
13. KPIs to track
14. Success checklist

If the user asks for a shorter proposal, use:

1. Cover page
2. Proposal overview
3. 3-month plan
4. 6-month plan
5. 12-month plan
6. What success looks like
7. Recommended option

## Executive Summary

Write 2-4 short paragraphs.

Mention:

- The site has an opportunity to grow.
- Competitors are stronger in some areas.
- SEO can improve direct enquiries, calls, sales, or leads.
- The plan focuses on local SEO, page improvements, content, internal linking, AI SEO, reviews, and authority.

Example:

> The website already has useful products and business trust, but competitors are getting more search visibility. This plan focuses on improving the important pages, building local trust, collecting reviews, and making the website easier for Google and AI search tools to understand.

## SEO Strategy Section

Include the main work areas:

### On-Page SEO

Explain simply:

- Optimize meta titles and descriptions.
- Improve H1/H2 headings.
- Revamp important pages.
- Improve product/category/service content.
- Add FAQs.
- Improve image alt text.
- Make pages easier to read and act on.

### Local SEO

Include:

- Google Business Profile improvement.
- Review growth plan.
- Address/phone/hours consistency.
- Local schema.
- Local citations.
- Location page improvements.
- Service-area targeting.

If reviews are weak, highlight it:

> Important: The business currently has 0 reviews, while competitors have 50+. Review growth should start immediately because reviews help local trust and conversion.

### Internal Linking

Include:

- Link related pages together.
- Link blogs/guides to service/category/product pages.
- Link homepage to priority pages.
- Add links from high-traffic pages to money pages.
- Use simple anchor text that customers understand.

Example:

> Internal linking helps Google understand which pages are most important and helps visitors move from information pages to enquiry or product pages.

### Content Revamp

Include:

- Rewrite thin pages.
- Add buyer-focused explanations.
- Add FAQs.
- Add product/service comparisons.
- Add location-specific sections.
- Add trust points.
- Add calls to action.

### AI SEO

Explain AI SEO in simple terms:

> AI SEO means making the content structure ready for AI search tools and LLMs. We will revamp pages with short answers, clear FAQs, summaries, schema, trust signals, and helpful sections so AI tools can understand the business and recommend it more confidently.

AI SEO activities:

- Add short answer sections.
- Add clear FAQs.
- Add page summaries.
- Add comparison tables.
- Add product/service explanations.
- Add schema markup.
- Add trust and proof sections.
- Structure content so AI tools can extract answers easily.

### Authority Building

Include:

- Local citations.
- Relevant directories.
- Supplier links.
- Partner mentions.
- Guest or industry content.
- Quality backlinks.

Avoid saying bulk backlinks.

## 30/60/90-Day Plan

Use when the user wants a near-term action plan.

Example:

| Timeline | Main Work | Expected Outcome |
|---|---|---|
| First 30 Days | SEO cleanup, tracking setup, metadata, headings, local SEO basics, page priority list. | Cleaner SEO foundation. |
| Days 31-60 | Revamp priority pages, add internal links, improve content, add FAQs and AI-ready sections. | Stronger pages for ranking and conversion. |
| Days 61-90 | Build reviews, citations, backlinks, publish new content, improve AI SEO, monthly reporting. | Better trust, authority, and lead tracking. |

## 3/6/12-Month Plan

Use when the user asks for a proposal.

### 3-Month Plan

Break it into Month 1, Month 2, Month 3.

| Month | Work | Simple Outcome |
|---|---|---|
| Month 1 | SEO cleanup, page priority list, meta titles, descriptions, headings, image alt text, tracking. | The foundation becomes cleaner. |
| Month 2 | Revamp priority pages, add internal links, improve FAQs, product/service answers, and AI SEO sections. | Important pages become more useful and AI-ready. |
| Month 3 | Improve local SEO, Google Business Profile, local schema, review growth, keyword tracking, and reporting. | Stronger trust and early ranking movement. |

### 6-Month Plan

Include:

- Expand category/service pages.
- Publish helpful content.
- Build reviews.
- Build citations and quality backlinks.
- Improve internal linking.
- Improve conversion paths.
- Continue AI SEO improvements.

### 12-Month Plan

Include:

- Long-term content growth.
- Authority building.
- Local SEO management.
- AI SEO optimization.
- Review growth.
- Technical maintenance.
- Monthly reports.
- Annual strategy review.

## Page Roadmap

Create a table of pages to build or improve.

| Priority | Page | Purpose | CTA |
|---|---|---|---|
| High | Main service/category page | Main commercial ranking page. | Call, enquire, buy, book. |
| High | Location page | Capture local searches. | Get directions, call, request quote. |
| Medium | FAQ/guide page | Answer customer questions. | Link to service/product pages. |

## KPIs To Track

Include simple KPIs:

- Organic traffic.
- Organic keywords.
- Keyword positions.
- Google Business Profile calls.
- Direction requests.
- Website clicks.
- Form submissions.
- Phone calls.
- Sales/enquiries.
- Review count and rating.
- AI visibility/citations, if available.

## Recommended First Focus

End with a clear recommendation.

Example:

> Recommended first focus: Start with a 6-month plan. Three months can fix the foundation, but six months gives enough time to improve pages, build reviews, publish content, and begin closing the competitor gap.

## Final PDF Checks

Before delivery:

- Render the PDF pages as images.
- Check that screenshots fit properly.
- Check that text is not cut off.
- Check table spacing.
- Check page numbering.
- Confirm the initial ranking screenshot is not included unless requested.
- Confirm the final file opens correctly.

## Output Naming

Use clear filenames:

- `brand-name-seo-plan.pdf`
- `brand-name-seo-proposal.pdf`
- `brand-name-seo-plan-redesigned.pdf`

Examples:

- `custompack-seo-plan.pdf`
- `budget-beds-seo-proposal.pdf`
- `signet-motors-seo-plan-redesigned.pdf`
