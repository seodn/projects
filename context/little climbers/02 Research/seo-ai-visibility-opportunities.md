# SEO And AI-Search Visibility Opportunities

## Strategic Summary

Little Climbers' best visibility opportunity is to move beyond broad "childcare Auckland" pages and become the most useful local answer for parents in each actual centre area.

The site should rank and be cited for:

- local childcare searches
- parent decision questions
- affordability/subsidy questions
- settling and school-readiness questions
- transport and meal questions

## Main SEO Problem

The current site has pages, but much of the copy is generic and repeated. It does not yet fully use the strongest transcript facts:

- small centres
- local community detail
- transport by centre
- meals by centre
- specific school links
- individual development plans
- parent aspirations
- subsidy support
- parent journey

## AI-Search Visibility Opportunities

AI systems favour clear, extractable answers. Little Climbers should add concise answer blocks like:

- "Which Little Climbers centres offer pickup and drop-off?"
- "Does Little Climbers provide meals?"
- "Does Little Climbers offer 20 Hours ECE?"
- "Does Little Climbers help with WINZ childcare subsidy?"
- "Which Little Climbers centre is near Willowbank Primary?"
- "Which Little Climbers centre is near Kingsford Primary?"
- "What age groups does each Little Climbers centre accept?"
- "What should parents ask during a childcare tour?"

## Structured Data Recommendations

Use schema where technically possible:

- Organization schema on homepage
- ChildCare or LocalBusiness schema for each centre page
- FAQPage schema for FAQ sections
- Breadcrumb schema
- Person schema for founders if profiles are added
- Article schema for guides/blogs
- Review schema only if reviews are implemented according to Google's rules and not marked up incorrectly

## GBP And Local SEO Recommendations

For each Google Business Profile:

- link each GBP listing to its matching location page
- use consistent name, address, phone, hours
- upload centre-specific photos
- add services where appropriate
- add posts about visits, school readiness, transition visits, food, transport and subsidies
- answer GBP Q&A with the same facts as the website
- collect reviews by centre
