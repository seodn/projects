# Internal Linking Structure

## Purpose

This internal linking structure keeps the existing top-level menu unchanged while making the childcare centre, kindergarten, and home-based pages work together as connected SEO assets.

The goal is to:

- support parent journeys from information pages to centre enquiries
- strengthen the four real childcare centre pages
- keep kindergarten pages connected to the matching centre pages
- keep home-based care separate unless Little Climbers confirms it should be part of the main centre journey
- avoid thin, isolated location or service pages

## Core Linking Rules

Each SEO page should include:

1. one link to its parent hub
2. one link to the matching service or location page
3. one link to a trust page, usually `/transition/` or `/our-curriculum/`
4. one conversion link, usually `/book-a-visit/` or `/contact-us/`
5. one or two closely related links only, instead of linking to every page from every page

Use descriptive anchor text. Avoid generic anchors like "click here" or "read more".

### Childcare Location Page Link Placement

For each childcare centre page, place links in this order:

1. near the top: link to `/childcare-centres/`
2. learning or curriculum section: link to `/our-curriculum/`
3. school-readiness or settling section: link to `/transition/`
4. preschool/kindergarten section: link to the matching kindergarten page
5. final CTA: link to `/book-a-visit/` and `/contact-us/`

## Notes For Content Creation

- The four childcare centre pages should remain the strongest local SEO pages.
- Kindergarten pages should link to the matching childcare centre pages to avoid becoming isolated or thin.
- Home-based pages should link to each other and conversion pages, but should not be blended into centre-based claims unless Little Climbers confirms the intended relationship.
- Do not create separate nearby suburb pages for Papatoetoe, Otahuhu, Manurewa, Botany, Flat Bush, Pokeno or Drury unless each page has enough useful local detail and proof.
- Keep all claims fact-safe. Do not invent hours, fees, transport rules, meal inclusions, school partners or staff details.
