# Bed Studio Content Production Roadmap

Updated: 29 July 2026

## Wave 1: Build Foundation

1. Homepage.
2. Newmarket showroom.
3. Mattresses.
4. Beds & Bases.
5. Headboards.
6. Storage beds.
7. Adjustable beds.
8. NZ-made beds and mattresses.

Outcome: a credible premium site with clear commercial paths and local relevance.

## Wave 2: Trust And Conversion

1. About Bed Studio.
2. Contact.
3. Delivery and assembly.
4. Warranty and returns.
5. Finance and payment options.
6. FAQs.
7. SleepMatch hub.

Outcome: fewer unanswered buying questions and stronger showroom, enquiry and purchase confidence.

## Wave 3: Priority Products

Start with products marked `Core` in the production workbook. Each page requires unique copy, clean Bed Studio imagery, accurate variants, confirmed warranty/lead-time information and no Budget Beds leakage.

## Wave 4: Search Guides

Build the high-intent guides in the keyword map, then link them to the relevant collections and products.

## Content Workflow

1. Writer drafts from the approved brief and source workbook.
2. Product facts are checked against the latest export.
3. Client confirms claims, warranty, delivery, lead time, finance and offers.
4. SEO review checks keyword ownership, titles, descriptions and internal links.
5. Developer builds in the unpublished Prestige theme.
6. QA checks desktop, mobile, imagery, schema, forms, cart/checkout and tracking.
7. Page is approved before indexing.

## Definition Of Ready

A page is ready to write only when its target intent, source facts, CTA and required proof are clear.

## Definition Of Done

A page is done only when copy, imagery, metadata, internal links, schema, mobile layout, tracking and client approval have been checked.
