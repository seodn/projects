# PRA Developments

Marketing context and website action plan for [PRA Developments New Zealand](https://pradevelopments.co.nz/), prepared 2026-09-10 from the client meeting, supplied summary, and public website review.

## Files

- [.agents/product-marketing.md](.agents/product-marketing.md) — Core business, audience, positioning, brand voice, buyer journey, evidence, open questions, and NZ/AU content rules. Uses the linked product-marketing skill’s structure.
- [action-plan.md](action-plan.md) — Prioritised execution tasks, suggested owners, dependencies, client approval gates, and completion checklist.

Read the context first, then the action plan. The `.agents` directory is inside this client folder to keep PRA’s context separate from other businesses in the repository. Tools working from the repository root should explicitly load this client-specific file.

This is working context, not approved live website copy. Facts, proposals, and verification gaps are labelled. Paiman’s review is required before publishing website copy. No full transcript, raw attachments, or customer contact lists are included.
