# BedStudio Context Pack

This is the BedStudio-specific working folder for the new website and launch work.

It keeps BedStudio separate from Budget Beds so the new site can be planned around its own positioning:

- premium showroom-led brand
- Newmarket-first local SEO
- Auckland secondary targeting
- NZ-made and customisable products
- showroom advice and trust
- clear delivery, warranty, payment, and FAQ content

## Folder Map

- `context/` - source-of-truth notes for BedStudio strategy, website, SEO, products, delivery, launch, and open questions.
- `content-drafts/` - copy briefs and templates to support website writing.
- `working-sheets/` - CSV planning sheets for pages, products, FAQs, and launch actions.
- `raw-sources/` - source summaries and redacted notes from meetings/emails.
