# Bed Studio Live Site Baseline

Checked: 29 July 2026

## Confirmed Current State

- Live domain: `https://www.bedstudio.co.nz/`
- Shopify theme published: Horizon/Radiant, schema version 3.5.1.
- Prestige is not the published theme. It is the shortlisted direction for the full build.
- The live site is still a holding/launch experience rather than the planned full catalogue website.
- Homepage title: `Bed Studio - Premium NZ Made Beds & Mattresses, Newmarket Auckland`.
- The homepage meta description is incomplete and needs rewriting.

## Sitemap Snapshot

- Product URLs: 114.
- Collection URLs: 2.
- Standard page URLs: 1 contact page.
- A blog sitemap exists, but the full guide programme is not yet built.

This imbalance means products are visible without the category, local and guidance pages needed to rank and help customers shop.

## High-Priority Risks

1. Imported product copy and image text still contain Budget Beds references.
2. The catalogue contains value-led or unrelated items that may weaken Bed Studio's premium position.
3. Category and collection depth is insufficient for Auckland and Newmarket search demand.
4. Metadata, internal linking, image alt text, product schema and collection copy require a full QA pass.
5. Exact Google positions are not confirmed because Search Console and a rank tracker were not available.

## Safe Build Approach

1. Keep the current live holding site stable.
2. Install Prestige as an unpublished theme after purchase/licensing is confirmed.
3. Build and QA the production structure in the unpublished theme.
4. Publish only approved collections and products.
5. Preserve old URLs where useful. Prepare redirects only for URLs deliberately changed or removed.
6. Run desktop, mobile, checkout, analytics and SEO QA before switching themes.

## Evidence Notes

This is a public-site and sitemap snapshot. Recheck immediately before launch because Shopify content can change quickly.
